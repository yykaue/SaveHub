# SaveHub 1.1.5 验收记录

发布日期：2026-11-06（Asia/Shanghai）。发布平台：Windows x64 / macOS arm64 (Apple Silicon)。

## 本次调整

| 调整模块                 | 发布行为与改进细节                                                                                                                                                                                                                  |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 恢复点保留策略           | 实现活动恢复点（默认 5 条）与已移除恢复点（默认 15 条）双队列管理；支持全局配置与单游戏覆盖；超额记录按修改时间（`updatedAt`）从早到晚软移除或物理清理；严谨处理 0 值禁用与批量找回上限拦截                                         |
| 读档事务与安全屏障       | 读档过程实行严格事务隔离，写前自动创建并校验安全副本（safety snapshot）；读档失败自动回滚；启动时自愈未完事务；损坏现场自动隔离到 `.restore-staging`，并通过 `blockedGames` / `assertGameWritable` 实施单游戏写入拦截，防止故障扩散 |
| 空间预算与容量预检       | 读档及创建快照前准确计算同卷合并及跨卷 safety/stage 峰值空间预算（含 5% + 64 KiB 预留余量），低空间时提前显式阻断，避免静默 I/O 写入崩溃                                                                                            |
| 分类日志与容量控制       | 引入 20 MiB 字节级上限的分类滚动日志（`classified-logger.mjs`），按 `info`/`warn`/`error` 分级记录存读档、导入导出、清理和恢复链路；支持全局行级安全淘汰与设置页一键打开日志目录                                                    |
| 游戏管理与工作区整合     | 统一并入「全部游戏」与「游戏管理」工作区；支持多游戏检索、元数据维护、自定义图标 URL 受控加载；支持游戏配置/存档一体化打包导出导入（combined game bundles）与安全物理清空（Game Purge）                                             |
| 前端架构与国际化深度适配 | 拆分页面与组件（LibraryPage, SettingsPage, ThemesPage, AllGames 等），实现全链路类型安全的中英双语字典（`zh.ts` / `en.ts`）；优化重复存档状态提示、四套主题色彩协调及进度面板精确阶段显示（`restoring` / `deleting` 等）            |
| 源码注释与代码可维护性   | 补充全工程主进程、渲染层、共享契约与测试脚本的核心逻辑中文注释，统一工程注释规范与可读性                                                                                                                                            |

> [!NOTE]
>
> 1. 旧版资料库无缝平滑兼容，升级到 1.1.5 无需手动迁移数据；旧版本缺少 `updatedAt` 的恢复点将自动以创建时间平滑初始化并持久化。
