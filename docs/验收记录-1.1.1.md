# SaveHub 1.1.1 验收记录

完成日期：2026-10-30（Asia/Shanghai）。本机验证环境：Windows x64。

## 五项调整

| 要求 | 最终行为 |
| --- | --- |
| 手动存档统计 | 原「全部存档」改为「手动存档」。列表、时光轴、侧栏及游戏卡片均不计入保护存档、回收站或读档恢复点；手动视图仍包含普通导入存档 |
| 读档前保存 | 保留保护标记和读档恢复点的独立分类。应用先自动保存当前进度并校验，成功后才替换游戏文件；自动保存失败会停止读档 |
| 收藏禁止删除 | 界面和文件操作层均拦截；批量所选中含任意收藏时，整批删除不执行；不能通过同时提交取消收藏和删除来绕过 |
| 批量收藏 | 提供收藏所选、取消收藏所选、收藏全部、取消收藏全部。全部范围为当前游戏未删除的手动与导入记录，包含保护存档，忽略搜索和筛选，不含回收站和读档恢复点 |
| 按名称导出 | 所选目标位置直接生成 A、B、C 等名称文件夹，内部为游戏原始内容，不增加 UUID 或 payload 层。重名自动编号，不覆盖已有目录 |

导出清单放在目标位置的 `.savehub-exports` 中，与实际游戏内容分开。携带清单可保留原名称、备注、收藏、保护和 SHA-256；支持导入整个输出目录或单份名称目录，并继续兼容旧版 `manifest.json` / `collection.json` 格式。非法文件名会替换为可跨平台使用的目录名，原名称保留在清单中。

每份导出均先校验源备份与暂存副本，再生成名称目录；正常失败时仅清理本次生成的目录。多个目录逐个提交，突然断电或进程被强制终止仍可能留下本次部分输出，原资料库和既有导出文件不会因此被主动移除。
