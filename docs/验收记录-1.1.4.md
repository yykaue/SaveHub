# SaveHub 1.1.4 验收记录

发布日期：2026-10-31（Asia/Shanghai）。发布平台：Windows x64。

## 本次调整

| 调整 | 发布行为 |
| --- | --- |
| 回收站保护限制 | 单份菜单和批量所选保护操作均禁用；存储层也拒绝修改回收站记录的保护标记。必须先找回，再保护。旧版已保护的回收站记录也可先找回，再取消保护 |
| 按钮文案 | 使用“保护所选存档”“取消保护所选存档”“保护全部存档”“取消保护全部存档” |
| 导出外层文件夹 | 单份、所选、全部存档和读档恢复点导出，均新建“游戏名-存档导出”文件夹，里面保留原来的存档名称目录和 `.savehub-exports` 清单 |

每次导出单独建立外层文件夹，同名时自动增加 ` (2)`、` (3)` 等编号。原始内容、校验、重复名称处理及失败清理继续有效；旧版命名导出和 `manifest.json` / `collection.json` 格式仍可导入。可以移动或分享整个外层文件夹，再直接选择它导入。
