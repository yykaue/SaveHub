# SaveHub 1.1.3 验收记录

完成日期：2026-10-31（Asia/Shanghai）。验证环境：Windows x64。

## 本次调整

| 要求 | 最终行为 |
| --- | --- |
| 全部存档 | 原“手动存档”更名为“全部存档”；列表、侧栏、游戏卡片、数量和容量统计均包含未删除的手动及导入记录，包含收藏和保护标记，不含回收站或读档恢复点 |
| 收藏与保护 | 两者都是同一记录上的标记，只改变筛选和操作限制。标记前后 ID、原始文件目录、记录数量不变，可同时出现在三个视图中 |
| 导出全部存档 | 按全部存档范围导出，包含收藏与保护记录，不受搜索或当前筛选影响，排除回收站和恢复点；继续以各存档名称建立文件夹，内部直接放真实游戏内容 |
| 多选和全选删除 | 正常恢复点可选择多份或全选后移除；回收站与已移除的恢复点可选择多份或全选后永久删除，均有二次确认 |
| 物理删除 | 在两个已删除列表中永久删除时，实际移除备份目录、内容和清单；完成后不可在应用中找回。确认框明确提示“永久删除，无法恢复”，并列出具体记录 |
| 多选和全选找回 | 回收站恢复到全部存档，已移除的恢复点恢复到正常恢复点列表，保留原 ID 和标记；找回不替换游戏当前进度 |

收藏仍允许删除，确认框醒目显示收藏数量与逐项标记，不增加额外确认门槛。保护记录在界面和文件操作层均禁止普通删除、永久删除，必须先取消保护。原有两个批量保护按钮及其混合状态规则保持有效。

正常删除只改变状态，不释放文件：普通存档进入回收站，恢复点进入已移除的恢复点。只有在上述两个列表再次确认永久删除，才真正删除备份文件。

## 中断和失败处理

永久删除前先检查整个选择范围的记录身份、已删除状态、保护标记与路径安全，拒绝跨游戏记录、重复 ID、越界路径和符号链接。真正清理前持久化删除状态，逐份返回成功与失败结果。

若清理部分文件后失败或退出，重新启动后仍可看到“永久删除未完成”的记录。此时只能继续永久删除，不能找回、编辑、添加保护或导出残缺内容。重试成功后清除剩余文件和删除状态。若失败发生在清理开始前，原记录仍可正常找回。
