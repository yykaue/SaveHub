# SaveHub 1.1.2 验收记录

完成日期：2026-10-31（Asia/Shanghai）。本机验证环境：Windows x64。

## 本次调整

| 要求 | 最终行为 |
| --- | --- |
| 收藏仅是标记 | 收藏不再阻止删除。单份和批量删除确认显示醒目的收藏提示；批量清单逐项标明“已收藏”，确认按钮正常可用，不增加额外确认步骤 |
| 保护禁止删除 | 界面及文件操作层均拦截删除保护存档。批量选择包含任意保护记录时，整批删除不执行。必须先取消保护，不能通过一次请求同时取消保护并删除来绕过 |
| 两个批量保护按钮 | 替换原有四个批量收藏按钮，分别处理所选记录和当前游戏全部未删除的手动及导入记录。全部范围包含保护存档，不受搜索或筛选影响，不含回收站与读档恢复点 |

| 对应范围的保护状态 | 所选按钮 | 全部按钮 | 操作 |
| --- | --- | --- | --- |
| 全部已保护 | 取消保护所选 | 取消保护全部 | 统一取消保护 |
| 全部未保护 | 保护所选 | 保护全部 | 统一添加保护 |
| 混合 | 保护所选 | 保护全部 | 统一添加保护 |
| 没有记录 | 保护所选，禁用 | 保护全部，禁用 | 无操作 |

单份收藏和取消收藏仍通过每行星标操作。保护与收藏相互独立，切换保护不会改变收藏、ID、创建时间或原始内容。删除后收藏标记保留，找回时仍是已收藏状态。读档恢复点与手动保护存档继续独立管理。
