# SaveHub 1.1.0 验收记录

完成日期：2026-10-30（Asia/Shanghai）。本机验证环境：Windows x64。

## 本次六项要求

| 要求 | 最终行为 |
| --- | --- |
| 唯一主题入口 | 移除侧栏主题按钮，只保留右上角主题切换 |
| 主题页往返 | 再次点击右上角返回上次页面；不选择主题、重选当前主题或更换主题均可返回；游戏、筛选、搜索、排序、勾选和滚动位置保留 |
| 全部存档排除保护 | 列表显示普通手动和导入存档，排除保护标记、回收站和自动恢复点；普通收藏仍显示 |
| 复选与排序 | 每行复选、全选当前列表、批量删除或导出、导出全部；名称、创建时间、文件大小表头均支持正序/倒序，默认创建时间倒序 |
| 标记与真实存档分离 | 收藏、保护、回收站沿用原存档 ID 与内容，不生成副本；自动备份独立作为读档恢复点保存 |
| 页面过渡 | 路由、主题、筛选、排序和弹窗变化带过渡效果；遵循系统减少动态效果设置；连续切换不会留下未处理的动画取消错误 |

批量删除会展示选中的名称，再添加回收站标记；找回后保留收藏和保护标记。回收站中的保护标签也可以独立切换，不会把存档意外移出回收站。

「导出所选」只弹一次目录选择，输出一个包含每份完整存档及 `collection.json` 的集合。集合可以重新导入，保留收藏和保护标记。「导出全部存档」按当前游戏的普通存档计算，不受搜索、当前筛选或勾选状态影响。取消选择导出目录不会生成文件。

旧版自动备份仍保留在原位置，新版在「读档恢复点」中展示；不需要批量迁移或复制旧资料库。恢复点可恢复、导出、移除及找回。
