# SaveHub v1.1.5 Release Notes / 发布说明

SaveHub v1.1.5 带来了重大的存储架构升级与全方位的使用体验优化。本次更新重构了读档事务与崩溃自愈机制，引入活动/移除双队列恢复点淘汰策略与 20 MiB 分类滚动日志，全面整合了游戏工作区管理，并完成了端到端中英双语国际化与全工程核心逻辑注释。

---

## 🚀 核心新特性 (Highlights)

### 1. 读档事务回滚与崩溃隔离屏障 (ACID Restore Transactions & Recovery Barrier)

- **事务级替换保证**：读档操作前自动创建并校验安全副本（Safety Snapshot），若替换过程中发生任何 I/O 异常，自动精确回滚原存档。
- **崩溃自愈与隔离**：遇到断电或进程强制中断等极端情况，应用重启时自动检测事务日志并恢复；若数据损坏则自动隔离现场至 `.restore-staging`，并通过 `blockedGames` 单游戏写保护拦截写操作，防止破坏其他正常游戏。
- **空间预算预检**：在写盘前严格计算同卷/跨卷 safety/stage 峰值空间需求（包含 5% + 64 KiB 余量），杜绝因磁盘空间满导致的静默写坏。

### 2. 双队列恢复点自动保留策略 (Dual-Queue Restore Point Retention)

- **活动与已移除双队列**：读档恢复点细分为「活动恢复点」（默认上限 5 条）与「已移除恢复点」（默认上限 15 条），支持全局设置与单游戏个性化覆盖。
- **稳定时序淘汰**：超出上限时，依据记录修改时间（`updatedAt`）从早到晚流转，活动超额先软移除，已移除超额再彻底清理。
- **批量找回边界保护**：恢复点找回操作严格校验批次上限，严防超额操作与非法并发修改。

### 3. 分类滚动日志与容量限制 (Classified Logging & Size Control)

- **20 MiB 字节级上限**：实现多通道分类日志器（`classified-logger.mjs`），按 `info`、`warn`、`error` 分级记录存读档、导入导出、清理和恢复全生命周期操作。
- **整行滚动淘汰**：保证日志全局严格控制在 20 MiB 内，超额时按行安全淘汰最早记录；设置页支持一键直达日志物理目录。

### 4. 统一游戏工作区与跨平台包迁移 (Unified Game Management & Bundles)

- **全游戏工作区整合**：全新改版「全部游戏」列表，支持多游戏集中展示、模糊搜索、排序与元数据编辑，自定义图标支持受控本地 URL 加载。
- **游戏配置与存档一体化打包**：支持游戏与全量存档合并导出（Combined Game Bundle），单文件可无缝跨平台在不同设备间迁移导入。
- **安全物理清空 (Game Purge)**：支持在删除游戏时选择彻底物理清理磁盘文件，具备持久化删除意图与重启恢复保证。

### 5. 全链路国际化与界面交互打磨 (Full i18n & Polished UI)

- **端到端多语言**：前端实现强类型双语字典（`zh` / `en`），后端系统级错误通过 `AppError` 结构化映射多语言描述。
- **细节体验优化**：优化重复存档冲突提示与批量覆盖逻辑；读档确认弹窗清晰呈现安全副本提醒；操作进度面板精准支持 `restoring`、`deleting` 等所有细分阶段。
- **四套主题全面适配**：对暗黑、深蓝、森林绿、复古等全部预置主题完成高对比度与配色校准。

### 6. 工程规范与注释强化 (Engineering Standards & Docs)

- **核心逻辑注释**：对主进程存储引擎、事务管理器、IPC Schema、渲染层组件及辅助测试脚本补充了详实的中文注释。
- **质量保障矩阵**：全量 144 项核心单元测试全部通过，严格执行 TypeScript 类型检查、ESLint 代码规范与 Prettier 格式化检查。

## 🔄 升级说明与兼容性 (Upgrade & Compatibility)

1. **旧版无缝升级**：
   - 从 1.1.4 或更早版本升级时，**无需手动迁移已有资料库**。新版启动时会自动兼容历史配置，旧版缺省修改时间的恢复点将自动以创建时间平滑初始化。
   - 升级前请确保旧版本 SaveHub 已完全退出。
2. **macOS 首次运行提示**：
   - 本版本构建采用 ad-hoc 本地签名（`build.mac.identity: "-"`），其他 Mac 用户下载后首次打开若弹出“无法验证开发者”，请进入系统「设置」→「隐私与安全性」，找到提示并点击「仍要打开」即可正常运行。
3. **数据回退策略**：
   - 应用在每次修改全局资料库配置时均会保留一份 `library.json.previous` 备份；如需回退到旧版，使用备份文件覆盖即可平稳降级。

## 📋 校验码 (Verification)

发布产物的校验码将在构建发布后记录于 `SHA256SUMS.txt` 中。建议用户下载后通过终端进行哈希比对：

```bash
# macOS / Linux 校验
sha256sum -c SHA256SUMS.txt

# Windows PowerShell 校验
Get-FileHash -Algorithm SHA256 .\SaveHub-1.1.5-*
```
